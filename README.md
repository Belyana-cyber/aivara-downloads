# Aivara для Android

[**Скачать Aivara для Android**](https://github.com/Belyana-cyber/aivara-downloads/releases/latest/download/Aivara.apk)

[Версия, дата и список изменений](https://github.com/Belyana-cyber/aivara-downloads/releases/latest)

1. Откройте ссылку в Chrome на Android и скачайте Aivara.apk.
2. Откройте файл из «Загрузок». При запросе Android разрешите установку из этого браузера.
3. Для обновления устанавливайте поверх прежней Aivara. Не удаляйте её и не очищайте данные.
4. Перед обновлением сохраните резервную копию в профиле и запомните её пароль.

Если Android предлагает удалить прежнюю версию или сообщает о несовместимой подписи — остановитесь и сообщите разработчику. Если файл не открывается, проверьте «Загрузки» и свободное место.

Учётные записи GitHub и Expo для скачивания не нужны. Здесь размещены только APK и инструкции; исходного кода приложения нет. ZIP «Source code», автоматически создаваемый GitHub, не является приложением.
